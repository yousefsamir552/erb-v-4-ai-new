# خطة تطوير وتحديث نظام إدارة المصنع (Factory ERP)

خطة شاملة لتنفيذ التعديلات والتحسينات المطلوبة لإطلاق النظام الليلة: نافذة منبثقة متكاملة لتعديل صلاحيات الموظفين لكافة الأقسام، مرحلة التجميع وإرسال الموديلات للمطابع، تنبيهات نواقص أقمشة المخزن، حاسبة تكلفة القطعة، تصدير سجلات القص والفرز إلى إكسيل، وشريط تتبع خط الإنتاج البصري.

---

### مراجعة القرارات الحاسمة (User Review & Critical Decisions)

> [!IMPORTANT]
> تم استطلاع رأي المستخدم وتأكيد الخيارات التالية:
> - **نافذة تعديل الصلاحيات**: تصميم نافذة منبثقة نظيفة ومستقلة (Modal) تحتوي على بطاقات لجميع الأقسام الأربعة (المخزن، التصميم، القص، والفرز) مع تحديد مستوى الصلاحية (بدون / مشاهدة / تعديل) وحقل لتحديث كلمة المرور.
> - **الإضافات التشغيلية المعتمدة**:
>   1. مرحلة التجميع وتوريد الموديلات للمطابع (Stage 4 Print Shop & Assembly Dispatch).
>   2. تنبيهات هبوط مخزون الأقمشة والحاجة لإعادة الطلب في شاشة المخزن.
>   3. حاسبة التكلفة التقديرية للموديل والقطعة بناءً على أسعار خامات الأقمشة والإكسسوارات.
>   4. تصدير سجلات القص وسجلات الفرز إلى ملفات إكسيل CSV تدعم اللغة العربية.
>   5. شريط ومخطط بصري لمراحل خط الإنتاج ونسب الإنجاز على لوحة التحكم الرئيسية.

---

## 1. نظرة عامة على التحسينات (Overview & Value)

- **الهدف الأساسي**: تسهيل إدارة صلاحيات العمال والمشرفين في المصنع بدقة وأمان، واستكمال حلقة الإنتاج حتى تسليم الموديل للمطبعة أو خط التجميع النهائي، مع توفير مؤشرات مالية وتنبيهات استباقية لمسؤول المخزن والمالك.
- **الفئات المستهدفة**: مدير النظام (Sudo)، مالك المصنع (Owner)، أمين المخزن، مقصدار القص، ومسؤول الجودة والفرز.

## 2. تجربة المستخدم والتصميم البصري (UX & Visual Design)

```
┌────────────────────────────────────────────────────────────────────────┐
│                   نظام إدارة المصنع - خط سير العمل                      │
│                                                                        │
│  [1. المخزن]  ──>  [2. التصميم]  ──>  [3. القص]  ──>  [4. الفرز]       │
│  تنبيهات نقص       حاسبة التكلفة      سجل القص         طباعة ورقة       │
│  الأرصدة           وحجز الخامات       وتصدير Excel     وتصدير Excel    │
│                                                            │           │
│                                                            ▼           │
│                                                   [5. التجميع والمطابع]│
│                                                   تسليم الشغل للمطبعة  │
└────────────────────────────────────────────────────────────────────────┘
```

1. **نافذة تعديل الصلاحيات المنبثقة (User Permissions Modal)**:
   - بدلاً من التعديل المزدحم داخل صف الجدول، يفتح زر "تعديل الصلاحيات" نافذة أنيقة بمنتصف الشاشة.
   - 4 بطاقات واضحة للأقسام: 📦 المخزن | 🎨 التصميم | ✂️ القص | 🔍 الفرز والجودة.
   - لكل قسم 3 خيارات: ❌ بدون وصول | 👁️ مشاهدة فقط | ✏️ تعديل كامل.
   - حقل لتحديث كلمة المرور واختيار الدور (Staff / Owner).

2. **لوحة التحكم وشريط مسار الإنتاج (Production Pipeline Tracker)**:
   - شريط تقدم مرئي أفقي متدرج يوضح توزيع الموديلات الحية على الأقسام الأربعة ونسبة الإنجاز الكلية.
   - إحصائيات سريعة للقطع المنتجة ونسبة الجودة العامة.

3. **تنبيهات نواقص الأقمشة في المخزن (Low Stock Warnings)**:
   - شريط تنبيهات ذهبي/أحمر في أعلى شاشة المخزن للأقمشة التي قل رصيدها المتاح للتصميم عن الحد الأدنى، مع اسم المورد ورقم هاتفه لسرعة إعادة الطلب.

4. **حاسبة تكلفة الموديل والقطعة (Cost Calculator)**:
   - داخل شاشة تفاصيل الموديل: عرض إجمالي تكلفة الأقمشة المحجوزة (`سعر الكيلو × الكمية`) + تكلفة الإكسسوارات، وتقسيمها على عدد القطع المتوقعة لحساب "تكلفة القطعة الخام".

5. **تصدير سجلات القص والفرز إلى Excel**:
   - أزرار خضراء أنيقة `📥 تصدير سجل القص (Excel)` و `📥 تصدير سجل الفرز (Excel)` بترميز UTF-8 BOM الداعم للأحرف العربية.

6. **مرحلة التجميع والمطابع (Stage 4 Dispatch)**:
   - قسم فرعي للموديلات المنتهية من الفرز ('جاهز للطباعة / التجميع'): تسجيل اسم المطبعة أو خط التجميع، تاريخ التسليم، عدد القطع المسلمة، وتتبع عودتها للمصنع.

## 3. القرارات التقنية وهندسة النظام (Technical Architecture)

```
┌───────────────────────────────────────────────────────────────────────┐
│                           AppContext                                  │
│  - currentUser, users, updatePermissions                              │
│  - fabrics, fabricColors (low stock detection)                        │
│  - models, requirements, accessories (cost calculations)              │
│  - cuttingRecords (exportCuttingCsv)                                  │
│  - qcRecords (exportQcCsv)                                            │
│  - printDispatches (addDispatch, markReturned)                        │
└───────────────────────────────────────────────────────────────────────┘
                                   │
      ┌────────────────────────────┼────────────────────────────┐
      ▼                            ▼                            ▼
[SettingsView]              [WarehouseView]             [DesignDetails]
EditUserModal              LowStockBanner              CostBreakdownCard
(All 4 departments)        (threshold alerts)          (fabric + acc cost)
      │                            │                            │
      ▼                            ▼                            ▼
[CuttingDetails]            [QCDetails]                 [AssemblyDispatch]
ExportCuttingCsv           ExportQcCsv                 Dispatch to Print Shop
```

- **توسيع نموذج البيانات**:
  - إضافة واجهة `PrintDispatch` لتتبع تسليمات المطابع وورش التطريز والتجميع.
  - إضافة دالات `exportCuttingCsv` و `exportQcCsv` لتنزيل ملفات الجداول الزمنية.
  - دعم سعر الكيلو `price_per_unit` وتكلفة الإكسسوارات في حاسبة التكلفة التقديرية.
