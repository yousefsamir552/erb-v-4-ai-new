# نظام إدارة المصنع (Factory ERP) - React & TypeScript

نظام متكامل لإدارة وتتبع خطوط إنتاج مصانع الملابس الجاهزة، تمت إعادة بنائه كلياً باستخدام **React 19 + TypeScript + Vite + Tailwind CSS v4** مع الحفاظ الكامل على كافة العمليات الحسابية ومنطق العمل.

## أقسام النظام والميزات المنقولة:

1. **لوحة التحكم الرئيسية (Dashboard)**:
   - مؤشرات أداء فورية لعدد الموديلات، ألوان وخامات الأقمشة، والمستخدمين النشطين.
   - متتبع مسار دورة حياة الموديل (تصميم -> قص -> فرز وكنترول -> جاهز للتجميع والطباعة).
   - جدول أحدث الموديلات المسجلة مع روابط سريعة للتحكم.

2. **قسم المخزن والأقمشة (Warehouse)**:
   - تصنيف الخامات (قطن، ميلتون، ريب...) بالوحدات المناسبة (كيلو، متر، توب).
   - بطاقات ألوان الأقمشة مع معاينة الدرجة (Hex Color Swatches).
   - تتبع الأرصدة الفعلية وحساب **المتاح للتصميم** تلقائياً (`الكمية الفعلية - الكمية المحجوزة`).
   - تنفيذ حركات الصرف والإضافة وتسجيل كود الموديل الموجه له وسبب الحركة.
   - تصدير تقرير جرد المخزن إلى ملف CSV متوافق مع اللغة العربية في Microsoft Excel (BOM UTF-8).

3. **قسم التصميم والموديلات (Design & Models)**:
   - البحث والتصفح وتقسيم الصفحات (Pagination).
   - إنشاء الموديلات الجديدة وتحديد نوعها وفئات مقاساتها ورفع صورها.
   - **شاشة تلوين الموديل**: ربط كل قطعة (صدر، ظهر، أكمام، ياقة...) باللون المناسب من خامات المخزن وحجز الكميات المطلوبة في المخزن فورياً.
   - إدارة إكسسوارات الموديل (أزرار، سوستة، تيكت...) وتسجيل روابط الماركر الأساسي وماركر الطباعة وملاحظات القص.
   - **صرف القماش وبدء القص**: خصم الكميات المحجوزة تلقائياً من رصيد المخزن وتسجيل حركة صرف معتمدة ونقل الموديل إلى مرحلة القص.
   - الحذف الآمن للموديل (Soft Delete) مع تحرير الأقمشة المحجوزة إن وجدت.

4. **قسم القص (Cutting & Production)**:
   - عرض قائمة الموديلات التي تم صرف قماشها وتتواجد حالياً على بنك القص.
   - تسجيل بيانات الرقات: اختيار القطعة/اللون، اسم المقصدار، عدد الرقات، وزن الراق، والعدد الناتج من القطع، ودرجة الصبغة.
   - دفتر سجل القص التراكمي للموديل مع إجماليات الرقات والقطع.
   - إنهاء القص والتحويل إلى قسم الفرز والكنترول.

5. **قسم الفرز والكنترول والجودة (QC & Inspection)**:
   - شاشة الفرز مع إمكانية **طباعة ورقة استلام الفرز والجرد اليدوي للعامل** بنمط جاهز للطباعة الفورية (`window.print()`).
   - تسجيل الأعداد السليمة والمعيوبة مع ملاحظات العيوب لكل مقاس ولون، مع دمج الملاحظات وتراكم الأعداد آلياً.
   - مؤشرات فورية لإجمالي السليم والهالك ونسبة الهالك المئوية.
   - الاعتماد النهائي للفرز ونقل الموديل لحالة "جاهز للطباعة / التجميع".

6. **إعدادات النظام والصلاحيات (Settings & RBAC)**:
   - تعريف فئات المقاسات (بيبي، وسط، شبابي، رجالي...) وقيم المقاسات التابعة لها.
   - إدارة قائمة الموردين وأرقام هواتفهم.
   - إدارة حسابات الموظفين وصلاحياتهم متعددة المستويات (مخزن، تصميم، قص، فرز: بدون / مشاهدة / تعديل).
   - سجل المراقبة وتتبع العمليات (Audit Logs) مع عناوين IP وتاريخ ووقت كل إجراء.
